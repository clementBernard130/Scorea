## Coding Style

### Indentation

Utiliser 4 espaces.

Toujours indenter les blocs (if, for, while, fonctions, classes).

### Nommage
1. Variables et fonctions

Utiliser lowerCamelCase : `userName`, `getUserData()`, `maxValue`

2. Classes

Utiliser PascalCase : `UserController`, `EmailService`

3. Constantes

Utiliser UPPER_SNAKE_CASE : `MAX_RETRY`, `DEFAULT_TIMEOUT`

4. Fichiers 

Utiliser PascalCase

5. Base de données

Utiliser snake_case : `id`, `created_at`
